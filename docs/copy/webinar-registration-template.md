# Webinar Registration (Photo Hero) — Copy Template

**Use this to write the copy for a new webinar registration page.** Fill in every
`[BRACKETED]` field, then hand the finished doc to whoever builds the page.

**Modeled on:** public/webinar-registration/register-121726.html
**Live URL pattern:** theloanatlas.com/`[slug]`/ (e.g. `/register-121726/`)

**Pick this layout when:** it's a Loan Atlas–branded session, you have a strong hero
photo, and there may be one or more hosts. For a private session co-branded with a
partner company, use [webinar-registration-partner-template.md](webinar-registration-partner-template.md).

Page order: split hero (copy left, photo right) → about copy + "What you'll learn" list
→ dark "Hosted By" band (one block per host) → gold closing CTA card. The page uses a
minimal header (logo only, no nav). Registration happens on Zoom: every button opens
the Zoom registration page in a new tab.

A filled-in example is at the bottom.

---

## Page setup

| Field | What to write | Your copy |
|---|---|---|
| **Webinar title** | Two parts: a short label, a colon, then the promise. The label is shown in brass on the page. | `[LABEL]: [PROMISE]` |
| **Short title** | 2–4 words, for the mobile register bar. Usually the label. | `[SHORT TITLE]` |
| **Slug** | Lowercase, hyphenated. Date-based slugs (`register-MMDDYY`) are fine. | `[slug]` |
| **Date** | Day + date, abbreviated. | `[Thu, Dec 17, 2026]` |
| **Time** | Primary time zone, plus a second time zone. | `[10:00 AM PT] / [1:00 PM ET]` |
| **Where** | Usually "Live on Zoom". | `[Live on Zoom]` |
| **Zoom registration link** | The full Zoom registration URL. | `[URL]` |
| **SEO title** | `[Webinar title] — The Loan Atlas` | |
| **Meta description** | 1–2 sentences, ~150–160 characters: who, what, and when. | `[META DESCRIPTION]` |
| **Hero photo** | Landscape-ish photo of the host(s), about 1200×950. Shown on the right of the hero. | `[image file]` |
