## Roles

## One Playbook for Your Whole Team

The Perfect Loan Process assigns every action to a role — so your client experience never depends on who happened to touch the file.

**Role 01 — Loan Originator**
Owns the first call, expectations and the under-promise / over-deliver standard.

**Role 02 — Transaction Coordinator**
Drives the file forward and keeps every party informed at each stage.

**Role 03 — Loan Processor**
Turns a clean file fast — the scripted handoff makes it seamless.

**Role 04 — Production Assistant**
Runs proactive touchpoints so clients feel cared for the whole way.
