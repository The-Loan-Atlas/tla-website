# Webinar Registration (Co-Branded Partner) — Copy Template

**Use this to write the copy for a private webinar run for a partner company.** Fill in
every `[BRACKETED]` field, then hand the finished doc to whoever builds the page.

**Modeled on:** public/webinar-registration/revolution-register.html
**Live URL pattern:** theloanatlas.com/`[slug]`/ (e.g. `/revolution-register/`)

**Pick this layout when:** the session is exclusive to one partner company and you want
their logo next to ours. It has one speaker, an agenda card grid and an FAQ. For a Loan
Atlas–branded session with a hero photo and/or several hosts, use
[webinar-registration-template.md](webinar-registration-template.md).

Page order: centered navy hero with Loan Atlas + partner logo lockup → "About This
Session" statement → agenda card grid → dark speaker band → FAQ → navy closing card.
The page uses a minimal header (logo only, no nav). Registration happens on Zoom: every
button opens the Zoom registration page in a new tab.

A filled-in example is at the bottom.
